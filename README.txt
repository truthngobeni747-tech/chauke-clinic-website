DR CHAuke MEDICAL PRACTICE — SAMPLE WEBSITE

Files:
- index.html: page structure and content
- style.css: styling, layout, responsive/mobile design
- script.js: mobile navigation, current year, and directions toast
- assets/clinic-photo.png: image supplied for the concept

HOW TO PREVIEW
1. Keep the folder structure intact.
2. Open index.html in a modern browser. An internet connection is used for the Google Fonts; the site otherwise runs locally.
3. To edit the website, open the folder in VS Code and edit the three separate files.

IMPORTANT BEFORE PUBLISHING
- Confirm the practice name, address, services, opening hours, phone number, and appointment process with the practice.
- The photo provided was used as a visual placeholder. Replace it with a clear, approved photo before launch.
- This is a front-end sample only. It does not submit appointment requests or store patient information.
